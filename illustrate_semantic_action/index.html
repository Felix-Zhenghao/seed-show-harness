Semantic actions in the robot base frame

Actual LIBERO renders, before and after one token. Each PNG contains Agentview (left) and Wristview (right). Click an image for full size. All 20 MV / RT / CAM tokens are shown from two starting orientations, with an identical simulator state restored before each action in a scenario.

FWD = base +X · RIGHT = base +Y · UP = base +Z. These axes stay fixed when the wrist or camera turns. Commanded rotations pivot at the TCP or camera; yaw CW is positive about +Z (viewed from below). Commanded base-frame deltas match across both starting orientations. Physical results also depend on the controller dynamics: these captures include up to 59.41 mm TCP position error and 6.91° rotation-vector error relative to the target after the configured control steps. The measured values below preserve those differences.

The gripper is moved forward 14 cm and down 12 cm before capture for visibility. The second scenario adds wrist yaw +60°, pitch −20°, and camera yaw +15°. Preparation uses 30 control steps per EEF action; the illustrated actions use these capture settings: 10 control steps, 10 cm EEF translation, 30° EEF rotation, 10 cm camera translation, 30° camera yaw. These illustration sizes leave the runtime defaults unchanged. Camera actions do not advance physics.
